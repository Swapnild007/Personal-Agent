# RADHA Agent Runtime

This directory is the new foundation for RADHA's general-purpose agent runtime.

The runtime will own:
- task lifecycle
- planning
- model interaction
- tool selection
- policy checks
- execution
- observation
- verification
- event streaming

Capabilities such as coding, research, data analysis and browser interaction plug into this runtime.

The existing coding-agent prototype remains available during the transition. It is not the final architecture.
